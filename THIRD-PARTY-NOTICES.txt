Windows libraries
-----------------
Windows supplies the Win32, GDI+, audio and other operating-system libraries.
They are not bundled in the portable archive.

GNU/Linux libraries
-------------------
The Debian package and native portable archive use the system GTK 3, GLib,
ATK, Pango, Cairo and ALSA libraries. No copies of those shared libraries are
included in those two packages. Their notices and applicable LGPL texts
are included in licenses/. These libraries keep their upstream licenses.
The AppImage bundles selected shared libraries and data files; its included
dependency manifest and component notices identify the exact shipped files.

Compiler runtime
----------------
The supplied binaries statically link portions of libgcc and libstdc++.
The applicable upstream and distribution notices, GCC Runtime Library
Exception version 3.1, and GPL text are provided in
licenses/GCC-RUNTIME-NOTICES.txt and licenses/GPL-3.0.txt.
The exception permits eligible independent applications linked with those
runtime libraries under the application's own license.

The Windows executable also uses MinGW-w64 runtime and import libraries.
Their component-specific notices are in licenses/MINGW-W64-NOTICES.txt.

Fonts
-----
Fonts are selected from the operating system at runtime. No font files are
included in the native portable or Debian packages.
